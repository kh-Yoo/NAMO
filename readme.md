내 손글씨로 만드는 메모와 일기

NAMO는 사용자가 직접 쓴 한글 자모를 디지털 글꼴로 만들어 메모와 일기에 적용하는 Flutter 앱입니다. 손글씨를 등록하고, 생성된 글꼴로 글을 쓰거나 TTF 파일로 내보낼 수 있습니다.

주요 기능

손글씨 등록: 한글 기본 자음과 모음을 직접 작성합니다.

한글 글꼴 생성: 입력한 자모를 초성·중성·종성으로 조합해 한글 음절을 만듭니다. 복합 자모와 겹받침도 처리합니다.

메모·일기 작성: 생성한 손글씨 글꼴을 앱 내 글쓰기에 적용합니다.

글꼴 복원: 앱을 다시 열어도 저장된 손글씨 글꼴을 불러와 적용합니다.

TTF 내보내기: 생성한 글꼴을 TTF 파일로 저장할 수 있습니다.

사용 흐름

한글 자음과 모음을 손글씨로 등록합니다.

NAMO가 자모를 조합해 한글 글꼴을 생성합니다.

생성한 글꼴을 앱에 적용해 메모와 일기를 작성합니다.

필요한 경우 글꼴을 TTF 파일로 내보냅니다.

개발 과정

한글 글자는 자모 조합에 따라 글자의 폭, 높이, 받침 위치가 달라집니다. 초기 생성 결과에서는 일부 글자가 작게 보이거나 글자 사이 간격이 고르지 않은 문제가 있었습니다. 이를 개선하기 위해 글자의 실제 영역을 기준으로 크기를 계산하고, 초·중·종성 조합별 위치와 크기를 조정했습니다. 특히 ㅗ/ㅡ + 받침 조합의 과도한 축소와 ㅎ의 형태 문제를 별도로 보정했습니다.

기술 스택

앱: Flutter, Dart

글꼴 처리: 한글 자모 조합, 글리프 영역 계산, TTF 생성

로컬 실행

Flutter 개발 환경을 준비한 뒤 프로젝트 루트에서 실행합니다.

flutter pub get
flutter run
